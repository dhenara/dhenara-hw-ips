# Host clock and reset crossings

The [CDC source list](../../rtl/cdc/files.f) contains a dual-clock FIFO, a single-entry bundled mailbox and their reset fence. These are technology-independent RTL. Their digital tests exercise independent clocks; no physical timing or metastability qualification is claimed.

Create each AXI, APB, host and channel clock with its actual integration period. Mark the `ASYNC_REG` stages as synchronizers using the implementation tool's supported attributes and preserve their placement. Do not insert combinational logic between synchronizer stages or duplicate their first-stage fanout. Each reset synchronizer releases only its own clock domain.

For every FIFO, constrain the Gray pointer bus from the source `wgray_q`/`rgray_q` registers to the corresponding first-stage `wgray_r1`/`rgray_w1` synchronizer. Bound the datapath delay and bit skew to less than the source clock period, with the technology's required margin. This preserves the one-transition-at-a-time observation assumption. The FIFO writer-local `w_pending_o` drain witness compares its publication pointer with the synchronized actual reader-consumption pointer; the AXI disable acknowledgement uses this witness to retain accepted descriptors until they import. A blanket asynchronous-clock false path can override these checks; review exception precedence rather than assuming the bound is active.

For each mailbox, the request toggle traverses two synchronization stages before the destination captures `payload_q` into `ddata_o`. Constrain that bundled datapath to arrive within one destination period, with the required setup/margin. The source retains every payload bit until the destination consumes the entry and acknowledgement crosses back. The payload bus is not an independently synchronized register bank.

The AXI endpoint's initialization exchange follows the same bundled-data rule: `recovery_config_q` in the core clock domain remains frozen from its request toggle through acknowledgement, and the AXI clock captures the whole configuration after two request synchronization stages. Bound this datapath to one AXI clock period with the required margin. Source settlement, abort settlement and admission-idle reductions are registered in the AXI domain before their control synchronizers. The disable request/acknowledgement token uses two stages in each direction and remains active while a payload link is aborted; preserve its independent raw-reset boundary.

The public bridge accepts asynchronous host and AXI reset assertions. It locally synchronizes host reset release and the common link release in the core clock. Each endpoint separately synchronizes its own AXI reset release for ledger/control state and the remote link release for its initialization controls. The quiesce-token control combines host and own AXI assertion, with AXI-local release. A remote reset cannot reset a surviving port's accepted ledger. These nested synchronizers add release latency; bypassing them or replacing them with a raw reset deassertion changes the reset-domain contract.

Constrain asynchronous resets and both reset-release synchronizers according to the target library's recovery/removal and reset-tree rules. Either endpoint reset asserts the link reset and the sticky transport fault asynchronously; deassertion passes through the two local reset synchronizers. FIFO `w_rearm_ready_o`/`r_rearm_ready_o` and mailbox `s_rearm_ready_o`/`d_rearm_ready_o` expose their actual owning fence's local reset release. Each owner must wait for every transport in its domain before issuing its domain-local rearm pulse after settlement and epoch replacement; an independent replica synchronizer or a fixed delay cannot establish that readiness. Channel and control links aggregate those witnesses at each end. The AXI bridge waits for all core-side witnesses, and the source retains the initialization request until its own actual readiness permits rearm. Initialization requires the matching acknowledgement and cleared transport faults. The source and destination fault controls each cross through two stages before transfers resume.

The integrator must resolve the actual synthesized register names, verify every intended collection is nonempty, inspect timing exceptions and run a structural CDC/reset-domain analysis on the combined netlist. This page gives required constraints; it is not a prequalified SDC for an unknown clock tree or technology.
